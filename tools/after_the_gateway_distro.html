The one-page cheat sheet

Print it, stick it inside the lid, and let the muscle memory build. Two tricks worth more than any command: press Tab to finish a file name for you, and press the ↑ key to bring back the last command. The amber rows are the ones that rescue you when the internet goes down; there's a whole post on that, Command Not Found.

CommandWhat it does
ip aInternet not working? Start here. Shows your IP address. A 169.254.x.x address means you never got a real one.
ip routeLook for the default via line. That's your way out.
ping -c 4 8.8.8.8Can you reach the internet by number? The -c 4 stops it after four.
pwdWhere am I?
lsWhat's in here?
cd DocumentsGo into a folder. cd .. goes back up.
mkdir nameMake a new folder.
cp a bCopy a file.
mv a bMove it, or rename it.
cat fileShow what's inside a file.
grep word fileFind a word in a file.
sudo apt updateRefresh the list of available updates.
sudo apt upgradeInstall them.
chmod 600 fileMake a file private to you.
man lsThe manual for any command. q quits.
df -h  /  free -hDisk space, then memory.
sudo ufw statusIs the firewall on?
rm fileDeletes for good. No Trash, no undo. Read twice.
